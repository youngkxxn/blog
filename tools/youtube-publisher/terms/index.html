1. 운영자 본인용 도구

Youngkxxn YouTube Publisher는 영권 채널 운영자가 자기 PC에서 사용하는 로컬 도구입니다. 일반 사용자의 가입·계정 연결·유료 이용 신청을 받지 않습니다. 이 안내 페이지에서 도구를 실행하거나 영상을 게시할 수 없습니다.

2. 계정 연결

Google 계정과 YouTube 채널의 소유자가 Google 인증 화면에서 권한을 승인해야 합니다. 도구는 연결된 채널 ID를 영권 @youngkxxn 채널과 대조합니다.

Google 계정의 접근·사용·저장·공유 및 연결 해제 방법은 개인정보처리 안내에 따릅니다.

3. 게시 작업

운영자는 게시할 영상과 제목·본문, 공개 상태·아동용 여부 등 게시 설정을 확인한 후 작업을 실행합니다. 게시할 콘텐츠에 필요한 권한을 보유하고 YouTube의 이용약관과 콘텐츠 정책을 따라야 합니다.

API 전송 완료와 YouTube의 영상 처리·공개 완료는 다를 수 있습니다. 도구의 결과 기록과 YouTube의 실제 상태를 확인해 게시 여부를 판단합니다. 결과가 불명확한 경우 기존 게시 여부를 확인한 뒤 재시도합니다.

이미지 카드뉴스 기능은 게시할 이미지와 본문을 준비하는 기능입니다. 커뮤니티 이미지 게시를 직접 생성하는 공식 API 기능을 제공하지 않습니다.

4. Google 서비스

인증과 동영상 전송에는 Google OAuth와 YouTube API를 사용합니다. 해당 서비스의 제공 조건과 사용 한도는 Google의 정책에 따릅니다.
