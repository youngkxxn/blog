일반 사용자의 가입이나 Google 계정 연결을 받는 서비스가 아닙니다. 이 홈페이지에서는 로그인·영상 업로드를 제공하지 않습니다.

어떤 일을 하나요

  1. 01

    게시할 내용 확인

    영상 파일, 제목, 본문, 공개 상태를 운영자가 지정합니다.

  2. 02

    정확한 채널 확인

    Google이 허용한 채널이 영권 채널인지 확인한 뒤 업로드합니다.

  3. 03

    업로드 결과 보관

    전송 진행 상태와 동영상 주소를 기록해 중단 후 재개와 중복 확인에 사용합니다.

대상은 권시아의 유튜브 채널 영권 @youngkxxn입니다. 이미지 카드뉴스는 게시용 파일과 본문을 준비하며, 커뮤니티 이미지 게시 자체는 별도의 게시 화면에서 진행합니다.

Google에 요청하는 권한

YouTube 동영상 관리 youtube.upload
운영자가 지정한 영상과 제목·본문 등을 YouTube에 업로드하는 데 사용합니다.
YouTube 계정 보기 youtube.readonly
연결한 채널의 이름·ID와 업로드한 영상의 처리 상태를 확인하는 데 사용합니다.

Google 계정의 비밀번호는 도구에 입력하지 않습니다. Google의 인증 화면에서 채널 소유자가 연결을 승인합니다.

계정 정보는 어디에 남나요

인증 토큰과 업로드 재개 주소는 운영자 PC의 Windows 자격 증명 관리자에 저장합니다. 영상·본문·작업 파일과 게시 결과 기록도 로컬 파일로 관리합니다. 이 도구는 계정 정보를 수집하는 자체 서버를 운영하지 않습니다.
